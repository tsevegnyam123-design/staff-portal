# Staff Portal — Гео-хязгаартай ирц + Google Sheets синк

## Ашиглаж буй систем

- Портал: https://tsevegnyam123-design.github.io/staff-portal/
- Supabase: `portal_v2_attendance`, `portal_v2_attendance_sites`
- Google Sheets: https://docs.google.com/spreadsheets/d/1Q_fKf_MUcmmgKVvOyTZx9R5cDi3xy4kiA1tJNaHfoJI/edit
- Google Apps Script код: `google-apps-script/AttendanceSync.gs`.

**Хувийн байршлын хөдөлгөөний түүх хадгалахгүй.** Ирц дарах үед
браузер GPS-ээ зөвшөөрснөөр сервер зөвшөөрсөн салбарын төв болон
радиустай харьцуулна. Ажилтны GPS координат ирцийн хүснэгт болон
Google Sheets-д хадгалагдахгүй; зөвхөн байрлалын хэмжилтийн
нарийвчлалыг хадгална. Браузер байршлаа илгээж чаддаг төхөөрөмжөөс
ашиглах шаардлагатай; хуурамч GPS-ийг бүрэн илрүүлэх баталгаа биш.

## Менежер: салбарын байршил тохируулах

1. Салбар дотор, GPS боломжтой утаснаас менежерийн эрхээр нэвтрэх.
2. **Ирцийн байршил** табыг нээх.
3. Радиусыг 50–500 м дотор тохируулах (эхний утга **150 м**).
4. **Энэ байршлыг төв болгох** товч дарж байршлын зөвшөөрөл олгох.
5. Менежер байршилд үнэхээр байгаа эсэхээ шалга. Тохируулга хийгдээгүй бол ажилтан
   **Ирсэн/Явсан** товч дарах боломжгүй.

Менежер байршлыг дахин тохируулах эрхтэй. GPS хэмжилтийн алдаа
100 м-ээс их байвал хүсэлт буцаана. Ажилтны тасралтгүй байршлыг
систем хянадаггүй.

## Ажилтан: Ирсэн / Явсан

Ажилтны хуудасны **Ирц бүртгэх** товч:

- **Ирсэн** — тухайн мөчийн серверийн цагаар ирцийг нээнэ.
- **Явсан** — нээлттэй ирцийг тухайн мөчийн серверийн цагаар хаана.
- Давхар **Ирсэн** / нээлтгүй **Явсан** дарахыг мэдээллийн сан хориглоно.
- Нэг өдөрт хэд хэдэн орж/гарсан бүртгэл байж болно (нэгэн зэрэг нэг нээлттэй бүртгэл).
- **Явсан дараагүй**: ирсэн өдрийн дараагийн **01:00** цагаар
  буруу/дутуу хаалт хийж, `auto_missing_out` төлөвтэй болгоно.
  SQL scheduler 5 минут тутамд шалгана, огноо нь **01:00** байна.
  Үүнийг **бодит ажилласан 9 цаг** гэж тооцохгүй, `Нийт ажилласан цаг` = `-`.
  Менежер дараа нь бодит баримтаар засварлах тусгай workflow шаардлагатай.

**Анхаарах ноцтой хязгаарлалт:** Одоогийн ээлжийн хуваарьт
**23:45–08:45 шөнийн ээлж** бий. 01:00-д автоматаар хаах хэрэглэгчийн
хүсэлт нь шөнийн ээлжийг 01:00-ээс хойш ажиллах боломжгүй болгож, “Явсан дараагүй”
гэж тэмдэглэх тул ночной ээлжийн тусгай тасалбарын дүрмийг менежер
шийдэж батлах хүртэл энэ системийг **бодит шөнийн цагийн цалин бодоход
шууд ашиглахгүй**. Хүсэлтийн дагуу 01:00 дүрмийг бүх бүртгэлд мөрдөнө.

## Google Sheets-ийн бүтэц

- **Номинзул**: эхний хэрэглэгчийн одоо байгаа жишээ бүртгэлийг хадгалсан.
- Бусад ажилтан бүр тусдаа, өөрийн нэртэй хуудастай.
- Ажилтны sheet: `Өдөр / Ирсэн цаг / Явсан цаг / Нийт ажилласан цаг / Тайлбар`.
- **Далд F багана** `Portal record ID` нь автоматаар бүртгэсэн мөрийг
  дахин давхардахгүйгээр шинэчлэхэд хэрэгтэй.
- **Info**: цалингийн `өмнөх 26 — одоогийн 25` хугацаагаар
  ажилтны код, нэр, салбар, хэвийн ирцийн хоног, баталгаатай ажилласан
  цаг, явсан дараагүй, нээлттэй ирцийг нэгтгэнэ.
- Явсан дараагүй бүртгэлийг **ажилласан цагт нэмэхгүй**.
- Анх хэрэглэгчийн гараар оруулсан мөрүүд автоматаар өгөгдлийн сан руу
  импорт хийгдээгүй; тэр мөрүүд хэвээр үлдэнэ. Порталаас шинээр орсон
  мөрүүдийг `Portal record ID`-аар ялгана.

## **Google Sheets автомат синкийг идэвхжүүлэх (заавал)**

⚠️ **Одоогоор код болон хуудсууд бэлэн, харин синк өөрөө зөвшөөрөлгүй
автоматаар ажиллахгүй.** Үүнийг нэг удаа тохируулах хэрэгтэй.

1. Нууц **32 буюу түүнээс олон тэмдэгттэй random token**-ийг өөрийн
   нууц орчинд үүсгэ. Чат/репозиторид бүү оруул.
2. <https://supabase.com/dashboard/project/zxhbufwncnijmpwzokvt/functions> →
   **Edge Functions → Secrets** дээр `GOOGLE_SHEETS_SYNC_TOKEN`
   нэртэй secret-ийг тэр token-оор үүсгэ.
3. Дээрх Google Sheets-ийг нээгээд **Extensions → Apps Script** сонго.
4. `google-apps-script/AttendanceSync.gs` файлын бүтэн кодыг Apps Script
   editor-т хуулж хадгал.
5. Apps Script **Project Settings → Script Properties** дээр
   `ATTENDANCE_SYNC_TOKEN` нэртэй property-д **яг ижил token** оруул.
6. Editor-оос `installAttendanceSync` функцийг сонгон **Run**
   хийгээд Google-ийн шаардсан албан ёсны зөвшөөрлийг зөвшөөр.
   Ингэснээр `synchronizeAttendance` 5 минут тутамд ажиллах
   **time-driven trigger** үүсгэнэ.
7. **Executions** таб дээр алдааг шалгаж, Google Sheet-ийн
   `Info` болон нэг ажилтны tab-д өөрчлөлт орж буйг баталгаажуул.

Token нь зөвхөн серверийн ирцийн экспортод зориулагдсан.
Ажилтны PIN, цалин, GPS координат, нэвтрэх сешн экспортод орохгүй.

Хэрэв 403 гарвал token хоёр талд ижил эсэхийг шалга.
Хэрэв 503 гарвал Supabase secret тохироогүй.
Google Sheet хувийн өгөгдөл агуулдаг тул **public share** болгож болохгүй.

## Тестлэх

- Байршил тохируулаагүй үед `Ирсэн` идэвхгүй.
- Зөвшөөрөгдсөн салбар дотор `Ирсэн` амжилттай;
  давхар `Ирсэн` буцаагдана.
- Гаднаас ирсэн/явсан дарахад сервер 403 буцаана.
- `Явсан` дарахад серверийн цагт `completed` төлөвтэй.
- 01:00-ээс өнгөрсөн нээлттэй ирц `auto_missing_out`; ажилласан цаг `-`.
- Синк дараалан хоёр ажиллахад Google Sheet-ийн мөр **давхардахгүй**.
- Шинэ ажилтны sheet автоматаар үүснэ.
- `Info`-д 26–25 мөчлөгөөр нэгтгэл гарна.
